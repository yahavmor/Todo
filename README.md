# Todo

A React and Redux todo app with users, a dashboard and an activity log.

**Live demo:** https://yahavmor.github.io/Todo/

<img width="1645" height="899" alt="Todo screenshot" src="https://github.com/user-attachments/assets/c28e58ad-ba60-4a6e-bd91-2358c79aeb2b" />

## Features

- Add, edit, complete and delete todos, each with an importance level
- Filter and search the list
- Todo details page, and a confirmation modal before removing
- Login and signup, and a user page with balance and activity log
- Dashboard with a chart
- About page with nested routes (team and vision)

## Tech

React, Redux and React Router, loaded in the browser (no build step). Data is kept in localStorage.

## Run locally

Serve the folder with any static server (for example the VS Code Live Server extension) and open `index.html`.
